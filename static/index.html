💰 시작 자금

모든 참여자는 동일한 시작 자금을 받습니다. 이 돈으로 주식을 사거나 예금하거나 현금으로 보유할 수 있어요.

⏱ 게임 진행
  • 상단 타이머에서 남은 시간을 확인하세요.
  • 복권은 자동으로 등장합니다 (60분 이하 2회 / 60~180분 4회 / 180분 초과 6회), 룰렛은 종료 5초 전 자동 등장.
  • 진행자가 게임을 일시정지할 수 있습니다.
📊 순위 확인

하단 메뉴 순위 탭에서 실시간 순위를 확인할 수 있습니다.

📈 매수 (사기)
  • 시장 탭에서 원하는 종목을 탭하세요.
  • 수량을 입력하거나 전량매수 버튼으로 가진 돈 전부 투자.
  • 매수 즉시 현금이 차감되고 주식이 보유됩니다.
📉 매도 (팔기)
  • 포트폴리오 탭 또는 시장에서 보유 종목을 탭하세요.
  • 수량을 입력하거나 전량매도로 한 번에 팔기.
  • 매도 즉시 현금이 지급됩니다.
🔄 주가 변동

주가는 실시간으로 오르내립니다. ▲ 빨간색은 상승, ▼ 파란색은 하락입니다.

⭐ 관심종목

종목 옆 ⭐를 눌러 관심종목으로 등록하면 필터 버튼으로 빠르게 확인할 수 있어요.

🏦 예금이란?

보유 현금을 은행에 맡겨 이자를 받는 기능입니다. 주식보다 안전하지만 수익이 제한됩니다.

💵 이자 계산
  • 이자는 예금 보유 시간에 비례해서 지급됩니다.
  • 게임 종료 시점에 자동으로 원금 + 이자가 현금으로 전환됩니다.
  • 예: 금리 3%, 30분 게임 중 15분 보유 → 이자의 50% 지급
🏷 상품 종류
  • 자유입출금: 기본 금리, 언제든 중도해지 가능 (중도해지 시 이자 없음)
  • 정기예금: 기본 금리의 1.5배, 게임 종료 전까지 중도해지 불가 — 유동성을 포기하는 대신 더 높은 수익을 노리는 상품입니다.
⚠️ 주의사항

예금 중인 돈은 주식 매수에 사용할 수 없습니다. 자유입출금 예금은 예금 탭에서 중도해지하면 이자 없이 원금만 돌려받습니다.

🎟 복권 (60분 이하 2회 / 60~180분 4회 / 180분 초과 6회)
  • 진행자가 복권을 시작하면 게임이 잠시 멈춥니다.
  • 1~45 중 6개 번호를 60초 안에 선택하고 제출하세요.
  • 당첨 번호와 많이 일치할수록 더 많은 상금을 받아요.
  • 6개 전부 일치하면 1등 상금 전액!
🎰 룰렛 (종료 5초 전 자동 등장)
  • 게임 종료 5초 전, 게임이 자동으로 일시정지되며 룰렛이 등장합니다.
  • 베팅할 금액을 입력하고 총 3번 도전 가능.
  • 결과: 꽝 / 1배 / 2배 / 5배 / 25배
  • 룰렛 중에는 게임 타이머가 멈춥니다.
